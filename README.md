# LocalPilot

SaaS B2B de gestion de la maintenance des locaux professionnels.

## Architecture

- `apps/api` : API REST NestJS
- `apps/web` : application web React
- `packages/shared` : contrats et types partagés

## Prérequis

- Node.js >= 24
- pnpm 12
- PostgreSQL

## Développement

Les applications seront initialisées progressivement après validation des fondations.
